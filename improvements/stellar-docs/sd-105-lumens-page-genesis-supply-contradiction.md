## Finding

The Lumens page contradicts itself about how lumens were created.

The Lumen Supply Metrics section opens with this sentence: "all XLM that has ever existed and will
ever exist was created when the Stellar network went live." The Definitions list on the same page
says otherwise. It says 100 billion lumens were created at launch. It then says network inflation
added 5,443,902,087.3472865 lumens until validators ended it on October 28, 2019.

A reader who quotes the first sentence gives a wrong history of the supply. The sentence also
hides the reason why `total_coins` reads about 105.44 billion.

## Evidence

Read-only reproduction:

```sh
curl -sS https://developers.stellar.org/docs/learn/fundamentals/lumens.md | grep -n "will ever exist"
curl -sS https://developers.stellar.org/docs/learn/fundamentals/lumens.md | grep -n "generated by inflation"
```

Both commands return a line. In `docs/learn/fundamentals/lumens.mdx` the first is line 48 and the
second is line 75.

## Recommendation

Replace the sentence on line 48 with text that agrees with the Definitions list:

> Unlike many other blockchains, lumens are not created through mining. One hundred billion lumens
> were created when the Stellar network went live. Network inflation added about 5.44 billion more
> until validators ended it on October 28, 2019. No mechanism creates new lumens today.

No other page in the docs repository repeats the old sentence.
