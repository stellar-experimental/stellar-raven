## Decision caveats and handoff

- This is a bounded factual recommendation to expire **only this case's sls-029 provider-Live partial cap**. Finding lifecycle/status was not inspected, so this report does not declare sls-029 `fixed-upstream`. The owner must reconcile its applicable lifecycle when editing caps; research itself makes no lifecycle change.
- No current Scout-vs-official Reflector contradiction was proved. Mainnet Beam's stale Scout observation is disclosed separately from its dated contract-existence label; testnet Beam unknowns are disclosed as unknowns.
- Official configs establish the published deployment footprint, not fresh state or price availability. No chain getters, signer thresholds, signatures, or deployed WASM hashes were independently rechecked. The author's earlier verification notes were not used to fill those gaps.
- Official website HTML is a JavaScript shell. Documentation text was recovered directly from the currently referenced official app bundle and its docs chunk, without executing them. `/pulse` and `/beam` routing and type filtering occur in the saved app bundle. Do not confuse the general `/docs` five-minute public-feed wording with every Beam product.
- Source tree HEAD was resolved through the GitHub API and pinned to `b006d297ac1a11dbf97de5f74b9e45dac1acb14a`; current source does not by itself prove deployed bytecode equality.
- No new conflict, corpus edit, answer/keyFact edit, test or compiler run is proposed by this lane. The regular requirements for scope, attribution and freshness remain independently applicable after the cap expires.
