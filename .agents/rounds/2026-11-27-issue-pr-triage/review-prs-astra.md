## #575 findings, highest severity first

1. **High — a false recurrence would undo an upstream fix.** `improvements/stellar-docs/sd-115-publish-teaches-deprecated.md:13,23,40` matches the spelling `publish(` and recommends replacing it. I checked the receivers on all 26 occurrences across seven pages and fetched all seven Markdown URLs directly (HTTP 200). Every call publishes a typed event. SDK 30 deprecates the two-argument `Events::publish(topics, data)`. Its `#[contractevent]` macro generates the one-argument method the pages use. Raven’s `improvements/resolved.json:1663–1677` records the original five raw calls on the auth and contract-spec pages. `gh pr view 3067 --repo stellar/stellar-docs` confirms the fix merged November 9. This proposed probe reports recurrence when it encounters the fix itself. [SDK raw method](https://github.com/stellar/rs-soroban-sdk/blob/414dd7dd95e6798db7d23899f94187017e41077d/soroban-sdk/src/events.rs#L125) · [Generated method](https://github.com/stellar/rs-soroban-sdk/blob/414dd7dd95e6798db7d23899f94187017e41077d/soroban-sdk-macros/src/derive_event.rs#L421) · [Live event guide](https://developers.stellar.org/docs/build/guides/events/publish.md) · [Merged upstream fix](https://github.com/stellar/stellar-docs/pull/3067)

2. **High — feed data can escape the finding directory.** `scripts/improvements-from-sdk-feed.mjs:49–51,135–136` constructs a path from the remote symbol. The slug helper changes underscores and leaves path separators and parent components intact. `scripts/lib/shared.mjs:76–81` writes a temporary file and renames it over the destination. On a write-enabled import, a malformed record can create or replace a Markdown file in another existing writable directory. The generated suffix limits the filenames affected. The four submitted symbols are ordinary identifiers. Use a validated Rust identifier, enforce destination containment and refuse overwrites before any write. [Importer](https://github.com/stellar-experimental/stellar-raven/blob/7c8e26406772421367e0d4d3cf6f64f5f698213d/scripts/improvements-from-sdk-feed.mjs#L48)

3. **High — future feed entries can select network targets for local and scheduled probes.** The importer takes the first supplied docs URL at line 70 and interpolates it into unquoted frontmatter at line 101. A different origin can become a probe target, and an embedded line break can change the parsed record structure. The base parser accepts indented properties. The probe runner includes `proposed` records and follows redirects on ordinary requests. A local probe run, or the daily refresh after such a record lands, can therefore make a request from the runner to an unintended destination. Authenticated probes bind the credential to an exact origin and reject redirects. All four submitted destinations are on the official Docs host. Derive probes from reviewed canonical page paths and serialize validated fields. [Parser](https://github.com/stellar-experimental/stellar-raven/blob/d39f0d6b11ebe75cbd15add60b280b4eddb16c95/scripts/improvements-lib.mjs#L141) · [Probe request](https://github.com/stellar-experimental/stellar-raven/blob/d39f0d6b11ebe75cbd15add60b280b4eddb16c95/scripts/improvements-run-probes.mjs#L78) · [Scheduled consumer](https://github.com/stellar-experimental/stellar-raven/blob/d39f0d6b11ebe75cbd15add60b280b4eddb16c95/.github/workflows/refresh.yml#L185)

An alternate `--feed` is still credited to the default URL at line 73. The upstream SQL counts distinct repositories by **call name**. It carries neither the Rust receiver type nor the caller’s SDK version. The 5,491 count cannot establish use of deprecated `Events::publish`. Feed strings also become agent-readable Markdown and, if a maintainer files the record, public issue prose. The filer passes an argument array to GitHub and scrubs coordination text.   python3 -c 'import hashlib,re,sys; b=sys.stdin.buffer.read(); print(len(b), hashlib.sha256(b).hexdigest(), len(re.findall(rb"^Source: https://[^\s]+[ \t]*$", b, re.M))); print({s:b.count(s.encode()) for s in ("publish(", "register_contract(", "register_stellar_asset_contract(", "register_stellar_asset_contract_v2", "keccak256(", "keccak256")})'
