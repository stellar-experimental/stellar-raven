# Addendum to the brief (the over-hedging check), same output file

Keep the brief's output format and columns unchanged. In the Basis column, additionally write `OVER-HEDGE` when a statement of the four kinds is
hedged or attributed only ("unverified", "according to X", "I could not confirm", "X claims") although a result in the packet returned a primary
record or an official Stellar family text (support class 1 or 2) that states it plainly. Write nothing for statements that were stated plainly.
Then, at the end of each packet section, add one line `Over-hedges: <n>` and, if any, name the result that supports it. At the end of the
file, in the Totals line, add `Over-hedges: <n>`. If a packet's final answer contains the sentence beginning "Audit, incident, governance and
standards-authorship claims are fact only when" inside a result, note `guard shown` on that packet's `Over-hedges` line.
